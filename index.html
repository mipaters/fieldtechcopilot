ExperiencePower Apps / Teams

Technician-facing mobile or Teams surface, using the operator's chosen frontline UX.

ConversationCopilot Studio

Conversational orchestration, agent instructions, approved actions, and channel integration.

KnowledgeAzure AI Search

Search indexed, approved DOCSIS, CPE, install, and plant documents; return grounded references.

IntegrationPower Platform + Azure

Connectors for Dataverse; API Management and Azure Functions for governed OSS / NMS reads.

TrustMicrosoft Entra ID + Azure Monitor

Role-aware identity, least privilege, DLP / connector controls, logs, and operational monitoring.

Answer path: technician question → Entra-authenticated copilot → question-scoped, read-only job/network context plus Azure AI Search over approved sources → cited answer and follow-up. A custom Azure AI Foundry model endpoint can be evaluated if the operator needs additional model deployment controls; it is an optional extension, not a second agent framework.

Non-autonomous by design: keep OSS / NMS connectors read-only for this copilot. Provisioning changes, plant adjustments, dispatch, work-order updates, and equipment control are outside its permissions; technicians and authorized network teams follow their existing approval workflows.
